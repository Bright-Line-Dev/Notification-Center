# ADR-002: انتخاب پایگاه داده

* **وضعیت:** Proposed
* **تاریخ:** 2026-09-29

## زمینه

داده‌های اصلی Notification Center رابطه‌ای هستند و شامل Application، Notification و Delivery می‌شوند. یکپارچگی داده و Transaction برای برخی عملیات مهم است.

## تصمیم

**PostgreSQL** به‌عنوان پایگاه داده اصلی انتخاب می‌شود.

* PostgreSQL: داده‌های دائمی
* Redis: Queue و داده‌های موقت

## دلایل

* ساختار رابطه‌ای پروژه با PostgreSQL تناسب دارد.
* Transaction و Constraintهای PostgreSQL برای حفظ یکپارچگی داده کافی و مناسب هستند.
* با Laravel به‌خوبی یکپارچه می‌شود.
* `JSONB` در صورت نیاز، امکان نگهداری Metadataهای منعطف را فراهم می‌کند.
* برای MVP ساده است و در صورت رشد پروژه نیاز فوری به تغییر Database ایجاد نمی‌کند.

## گزینه‌های ردشده

**MySQL:** گزینه قابل قبول بود، اما PostgreSQL برای نیازهای فعلی انتخاب شد.

**MongoDB:** به دلیل رابطه‌ای بودن مدل اصلی داده انتخاب نشد.

**Redis به‌عنوان Database اصلی:** فقط برای Queue و داده‌های موقت استفاده می‌شود.

## پیامد

Schema و Migrationهای پروژه بر مبنای PostgreSQL طراحی خواهند شد. در صورت تغییر اساسی در مدل داده یا نیازهای مقیاس‌پذیری، این تصمیم بازبینی می‌شود.
